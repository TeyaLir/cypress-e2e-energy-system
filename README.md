# E2E Test Suite — Industrial Energy Management System

Репозиторий содержит production-уровневые end-to-end тесты на **Cypress + JavaScript** для промышленного веб-приложения по управлению энергетическими системами (учёт паровых балансов, тепловых балансов турбоагрегатов, отчётность по форме 2-ПЭК).

Тесты написаны в рамках реального рабочего проекта и адаптированы для публичной демонстрации: конфиденциальные данные, URL и учётные данные заменены на тестовые.

---

## Стек и инструменты

- **Cypress 12** — E2E-тестирование
- **JavaScript (ES6+)**
- **cypress-real-events** — симуляция реальных браузерных событий (Tab, клики)
- **DevExtreme DataGrid** — тестируемый UI-компонент (промышленные таблицы с CRUD)
- **ESLint + Prettier** — контроль качества и единый стиль кода

---

## Архитектурные решения

**Модульная структура `support/`** — вся вспомогательная логика вынесена из тестов в переиспользуемые модули:

| Модуль            | Назначение                                                                                    |
| ----------------- | --------------------------------------------------------------------------------------------- |
| `loginTest.js`    | Аутентификация с поддержкой ролей (STANDARD, ADMIN)                                           |
| `toolbar.js`      | Операции панели инструментов: refresh, add, save, delete, reset |
| `pickDate.js`     | Шесть функций выбора дат: в поле, в попапе, внутри таблицы, по месяцу и по конкретному дню   |
| `rowHelpers.js`   | Заполнение и проверка строк таблицы: fillRow, checkRow, checkRowByIndex, checkRows            |
| `testData.js`     | Централизованное хранилище базовых URL, учётных данных, таймаутов и текстовых констант UI     |
| `e2e.js`          | Автоматический сброс тестовых данных перед запуском и переход на главную страницу перед каждым тестом                         |

**Поддержка разных типов ввода и проверки** — функции `fillRow` и `checkRow` из `rowHelpers.js` обрабатывают все типы ячеек: текст, число, чекбокс, выпадающий список, дата.

**Качество кода** — проект настроен с ESLint (плагин `eslint-plugin-cypress`) и Prettier. Правила включают запрет `cy.wait()`, контроль небезопасных цепочек команд и единый стиль форматирования.

## Покрытие тестами

### Бизнес-логика и расчёты

| Тест                                                    | Описание                                                                    |
| ------------------------------------------------------- | --------------------------------------------------------------------------- |
| `checkCalculatedData_energy_system.cy.js`               | Проверка корректности расчётов показателей эффективности энергосистемы      |
| `checkCalculatedData_first_line_steam_balance.cy.js`    | Валидация расчётов парового баланса основной производственной линии         |
| `checkCalculatedData_turbine4_heat_balance.cy.js`       | Проверка тепловых балансов и энергетических показателей турбоагрегата №4    |
| `checkCalculatedData_turbine3_heat_balance_cy.js`       | Проверка тепловых балансов и энергетических показателей турбоагрегата №3    |
| `checkCalculatedData_form2_pek_indicator205.cy.js`      | Тестирование расчётов отчётной формы 2-ПЭК (показатель 205, раздел 33.1.0) |

### UI и взаимодействие с таблицами

| Тест                        | Описание                                                                                                             |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `row_add_edit_delete.cy.js` | Полный CRUD-цикл: добавление, редактирование и удаление строк с проверкой персистентности после обновления страницы  |
| `row_edit_green_cell.cy.js` | Визуальная индикация изменённых ячеек при редактировании                                                             |
| `column_change_width.cy.js` | Изменение и сохранение ширины столбцов                                                                               |
| `column_move.cy.js`         | Перетаскивание и изменение порядка столбцов                                                                          |

### Аутентификация

| Тест                           | Описание                                                  |
| ------------------------------ | --------------------------------------------------------- |
| `password_restore.cy.js`       | Полный happy path восстановления пароля                   |
| `password_restore_error.cy.js` | Обработка ошибок и валидация при восстановлении пароля    |
| `input.cy.js`                  | UX-проверка фокуса при выборе приложения и подразделения  |

### API

| Тест                        | Описание                                                                    |
| --------------------------- | --------------------------------------------------------------------------- |
| `api_config_service_cy.js`  | Проверка endpoints сервиса конфигурации: доступность, подключение к БД, конфигурации всех микросервисов |
